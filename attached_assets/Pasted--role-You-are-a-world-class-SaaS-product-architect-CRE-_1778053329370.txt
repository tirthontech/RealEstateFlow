- Omnichannel lead capture: list every portal and ad platform per market with their lead push API details

- Lead timeline: every touchpoint logged with call recordings, email threads, WhatsApp messages, notes, documents in one chronological feed
- Dormant lead re-engagement: rules engine to auto-trigger re-engagement campaigns after inactivity

## SECTION 3 — AI & Automation Features
- AI lead scoring with LLM reasoning ("This lead is high-priority because...")
- Smart follow-up sequences: adaptive cadences based on lead behaviour
- Auto-draft property match emails: personalised per lead preference, pulls listing data
- AI conversation summaries: after every call/meeting, auto-generate structured notes
- AI-powered property valuation estimates integrated into the CRM
- Predictive pipeline: forecast deal close probability based on stage, days in stage, engagement
- AI chatbot for the client portal (answers FAQs, books viewings, sends listings)
- Natural language search: "Show me all leads who viewed 3+ properties and haven't responded in 7 days"
- AI-powered content generator: listing descriptions, social posts, email campaigns
- Voice-to-CRM: agents record voice notes, AI transcribes and structures into CRM fields

## SECTION 4 — Communication Suite
- Unified inbox: email (Gmail/Outlook OAuth), SMS, WhatsApp Business API, calls (VoIP via Twilio), all in one thread per contact
- Two-way email sync with full thread history
- SMS / MMS campaigns with per-country compliance (TCPA in US, PECR in UK, Spam Act in AU)
- WhatsApp Business API: bulk broadcasts, templates, chatbot handoff, opt-in management
- VoIP calling built-in: click-to-call, call recording (with consent banners per jurisdiction), voicemail drop
- Video meeting booking: Calendly-like scheduler embedded in CRM, auto-syncs to Google/Outlook calendar
- Automated follow-up bot: configurable sequences (Day 1 SMS → Day 3 email → Day 7 call reminder → Day 14 re-engagement)
- Communication templates with merge fields, per-language versions
- Broadcast campaigns with unsubscribe management and compliance footers

## SECTION 5 — Property & Listing Management
- Full listing inventory: photos, floorplans, virtual tour embeds (Matterport), pricing history, status
- Listing syndication: one-click publish to Zillow, Rightmove, Domain, REA, Immoscout, etc.
- Property matching engine: auto-match new listings to leads based on saved search criteria
- CMA (Comparative Market Analysis) tool: auto-pulls comparable sales, generates branded PDF report
- Open home / viewing scheduler: public booking page, auto-confirmations, SMS reminders, attendance tracking
- Offer management: track all offers per property, counter-offer workflow, status board
- Document vault per property: contracts, EPC, title deeds, inspection reports — all linked

## SECTION 6 — Transaction & Deal Management
- Deal pipeline: fully customisable stages per transaction type (sale, lease, commercial, off-plan)
- Transaction checklist: per-country templates (US: earnest money → title search → appraisal → closing; UK: offer → solicitor → survey → exchange → completion)
- Milestone tracking with automated notifications to all parties (buyer, seller, solicitor, agent)
- Commission calculator: split commissions, referral fees, franchise fees — auto-calculated on deal close
- DocuSign / Adobe Sign integration: send contracts directly from CRM, track signature status
- Conveyancing integration (AU: PEXA, UK: InfoTrack)
- Deposit and trust accounting tracker (non-transactional but shows balance status)

## SECTION 13 — Technical Architecture
Design the full system architecture covering:
- Frontend: Next.js 14+ (App Router), React Server Components, TypeScript, Tailwind CSS, shadcn/ui, Zustand, React Query
- Backend: Node.js with NestJS (modular, DI), GraphQL + REST hybrid API, BullMQ for job queues
- Database: PostgreSQL (primary, multi-tenant with row-level security), Redis (caching, sessions, queues), Elasticsearch (full-text search on leads/properties/docs)
- Multi-tenancy: schema-per-tenant vs row-level security — argue the tradeoff and choose with justification
- AI/ML: OpenAI GPT-4o (lead scoring reasoning, content generation, summaries), Whisper (voice transcription), LangChain for agents/tools, vector embeddings in pgvector for property matching
- File storage: S3-compatible (AWS S3 or Cloudflare R2), direct upload from client, signed URLs
- Email delivery: AWS SES + custom sending domain per white-label tenant
- Infrastructure: AWS (primary), multi-region (us-east-1, eu-west-1, ap-southeast-2 for AU/NZ), ECS Fargate (containerised), RDS Aurora PostgreSQL, ElastiCache Redis, CloudFront CDN
- Security: SOC 2 Type II path, GDPR DPA, pen testing cadence, encryption at rest (AES-256) and in transit (TLS 1.3), secrets in AWS Secrets Manager, MFA enforced
- Observability: Datadog (APM + logs + infrastructure), Sentry (error tracking), Uptime monitoring
- CI/CD: GitHub Actions → Docker build → ECR → ECS rolling deploy; branch preview environments on Vercel for frontend
- Rate limiting: per-tenant API quotas, abuse detection
- Data residency: EU tenants on eu-west-1, AU/NZ tenants on ap-southeast-2 (GDPR and Australian Privacy Act data localisation)
